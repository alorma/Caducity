# 05 · Textos (català)

Els mockups són en català. Claude Code ha de: (1) comprovar quins idiomes té l'app (`values/`, `values-ca/`, `values-es/`…), (2) afegir/actualitzar les claus, (3) traduir a la resta d'idiomes existents. Les claus són suggeriments.

## Veu
Segona persona del singular, frases curtes, verbs en imperatiu als botons (Afegeix, Desa, Congela, Llença, Esborra, Revisa). Sense exclamacions ni emojis. Dates relatives quan ajuden.
